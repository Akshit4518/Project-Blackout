# Project Blackout

## Overview
Project Blackout is a beginner-level C programming project that simulates a cybersecurity investigation.

The player takes the role of a security analyst investigating a fictional system outage at NexaCore.

## Features
- View system logs
- Analyse suspicious login activity
- Check user access permissions
- Reconstruct the incident timeline
- View collected evidence
- Generate a final investigation report

## Concepts Used
- C structures
- Arrays and strings
- Functions
- Loops and conditional statements
- Switch-case
- File handling
- Searching and sorting

## Technologies
- Programming Language: C
- Compiler: GCC
- Editor: Visual Studio Code

## How to Run

Compile:
`gcc blackout.c -o blackout.exe`

Run:
`.\blackout.exe`
